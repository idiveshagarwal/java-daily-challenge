# Day 226 — Hello World

## Problem

Print `Hello, World!` to standard output.

## Approach

A single `public class` whose name matches the file name, with the JVM entry point
`public static void main(String[] args)`. `System.out.println` writes the string to
stdout followed by a newline.

## Complexity

- Time: `O(1)`
- Space: `O(1)`

## Run

```bash
javac HelloWorld.java && java HelloWorld
```

## Output

```
Hello, World!
```
